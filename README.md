# Internship — License Plate Recognition

Developed a computer vision solution for **vehicle license plate detection and recognition** using **YOLOv8**. The project involved two main pipelines: training a license plate detection model using images annotated with **CVAT**, and processing detected characters to sort and reconstruct license plate numbers. The project was developed in **Python** using Google Colab, **YOLOv8**, **CVAT**, and **Roboflow**.

## 🎯 Project Objectives

* Detect vehicle license plates from images.
* Train a YOLOv8 object detection model using annotated images.
* Process and identify the characters contained in detected license plates.
* Sort the detected characters according to their position.
* Reconstruct the complete license plate number.

## 🔄 Project Pipelines

### 1. License Plate Detection

```text

       ↓

```

### 2. Character Processing & Plate Reconstruction

